# Store Screenshot Plan

All final screenshots must come from a release build. Do not upscale a smaller
capture and do not use the old “Rubik's” branding.

## Set A — App Store

- iPhone 6.9" hero: solved cube, complete UI
- iPhone 6.9" mid-twist: visible overshoot / jelly deformation
- iPhone 6.9" poke: ripple and indentation
- iPhone 6.9" drop: squash and plate shadow
- iPhone 6.9" extra sizes: 4×4, plus locked 5×5/6×6 treatment
- iPad 13" portrait and landscape: two-handed layout
- Optional 6.5" fallback set if required by App Store Connect

Use the exact current App Store Connect dimensions; the console rejects
incorrect sizes. Capture with the simulator status bar clean (no debug overlays).

## Set B — Google Play

- Phone: 2–4 screenshots, 9:16 or 16:9, min 320 px, max 3840 px
- 7"/10" tablet: 1–2 screenshots
- 512×512 icon: `store/google/icon-512.png`
- 1024×500 feature graphic: `store/google/feature-graphic-1024x500.png`
- No device frames that misrepresent the actual UI

## Set C — Huawei AppGallery

- HarmonyOS phone and tablet screenshots
- Start window / icon check
- No Android-only UI or debug branding

## State list

1. Solved hero
2. First twist / wobble
3. Poke ripple
4. Drop squash
5. Four cube sizes / IAP lock state
6. Tablet two-handed view
